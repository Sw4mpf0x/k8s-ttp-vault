# Setup

1. Clone this repo and [open it as a new vault](https://obsidian.md/help/manage-vaults#Create+vault+from+an+existing+folder) in [Obsidian](https://obsidian.md/)
2. Navigate to the `-- START HERE --` note as a starting point
3. Use links to navigate based on your current operating context

# Structure

* Reconnaissance and state changing actions are split into **reconnaissance** and **actions-on-objective** folders respectively
* The *references* folder contains more informational notes on different cluster features (e.g., `kubectl`, RBAC, network policies), components (e.g., FluxCD), or flavors (e.g., AKS)
